# Fictional review media

Six original illustrated characters and project covers created for Task 036.
They depict no real students and do not establish real competition membership
or awards. No source photographs, external identity assets or new media
dependencies are used. The six approved owner files remain outside this folder.

Each character has a transparent 690 × 780 upper-body portrait, a transparent
345 × 345 face crop and a 1280 × 720 project cover. These match the owner's
source image dimensions and use the same existing card/bubble sizing and fade.
The illustrations compress more than photographs; equal dimensions do not
establish equal network cost or production-scale performance.
